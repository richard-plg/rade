# Remove Tasks, Batches, Initiatives, Reports and their engines

Status: accepted 2026-10-23 (M33, PRD R101). Supersedes ADR-0018, ADR-0019, ADR-0020, ADR-0022, ADR-0023, ADR-0024, ADR-0025, ADR-0027 and the Tasks part of ADR-0028 (decisions 4, 5, 6's Verify clause and 7). Amends ADR-0029 (the Code page goes) and ADR-0030 (Impact no longer goes into Batch Reviewer or Initiative acceptance prompts). Approved design: docs/design/redesign-2026-10-23.md §1, §3.1, §9.

From M17 to M32 RADE grew a task manager (Tasks, Task Runs, the Definition of Ready, Profiles), an SDLC orchestrator (Batches, Initiatives, the Plan gate, Verified Runs and verify-command confirmation) and a reporting stack (Event Journal, Digest, Reports, Report Styles, export, Flow metrics, Lessons). The owner found them hard to use; M26 and M27 tried to hide them behind a simpler UI while keeping the engines, and the result is the current UI: a Project opened in the sidebar shows `Tasks · Start here 2/4` instead of its Sources (N1), Worktrees drift into No Project (N2), and one status is repeated in six or seven places. The redesign makes the Source link (ADR-0034) the centre of the app; the engines above are about a third of the code and every one of them reaches into the sidebar, palette, menus, state and socket.

## Decision

1. **Removed, not hidden.** Code, CLI commands, socket methods, skills, E2E suites, CSS and docs go for: Tasks (Task files, Task Runs, Task Detail, Board, Brainstorm, New Task dialog, Definition of Ready, `depends`, Task template v2, automatic Task status), Agent Profiles, Batches (scheduler, Batch Policy, Reviewer, Integration Branch, Run dialog and its presets, Running together), Initiatives (phases, document gates, Initiative Agent, milestones, acceptance Agent, Initiative Branch, feature cards), the Plan gate, Verified Runs and the verify-command confirmation, the Event Journal, Digest, Reports, Report Versions and Report Styles, Slack / DingTalk export, Flow metrics, Lessons, Start here, the Code page (Right Panel cheat-sheet and results page), and the UI for Named Bases (replaced by Source links, ADR-0034). Skills `rade-task`, `rade-batch`, `rade-initiative`, `rade-design`, `rade-report` are no longer installed; `rade setup` removes the copies it installed earlier.
2. **What replaces them.** The Event Journal is replaced by **Activity**: an in-memory list (Agent waiting / done, PR opened, commit, account limit events) shown in an Inspector tab; nothing is written to disk and nothing survives a restart. Code navigation keys, hover / peek / outline, `rade code …` and Impact stay; a navigation with more than one result (references, callers, call hierarchy tree, implementations, outline) shows in a results popover in the Viewer or Review Pane (one popover at a time, as R90), which also shows the server state (indexing, install hint, Restart). The Fan-out Judge keeps Impact in its prompt.
3. **Removed socket methods keep answering.** `task.*`, `batch.*`, `initiative.*`, `digest.*`, `report.*`, `flow.get`, `lessons.draft`, `plan.*` and the verify-confirmation methods, `debug.batch`, `debug.initiative`, `debug.reports` and the Task / Batch / Report ops of `debug.ui` return the JSON-RPC error `{"code": 2, "message": "'<method>' was removed in RADE 1.0.0 (ADR-0033)", "data": {"kind": "USAGE", "removed": "1.0.0"}}`. Unknown methods are already `USAGE` (API.md); `data.removed` tells a script or an Agent the method existed and is gone, so no new error kind is needed.
4. **Removed CLI commands exit 2.** `rade task`, `rade batch`, `rade initiative`, `rade digest`, `rade report`, `rade flow`, `rade lessons` print `rade: '<cmd>' was removed in 1.0.0 (ADR-0033)` on stderr and exit 2. `rade spawn --profile` and `--model` from a Profile go with them; Agent Presets keep `model_flag`.
5. **`state.json` goes from version 2 to 3.** The first 1.0 start writes `state.json.v2.bak` once (never overwritten), drops `plan_gates`, `tasks_page`, `Tab.task`, Batch / Initiative / Report fields and `start_here_dismissed`, and keeps every Workspace, Source, Worktree, Tab and Pane. A Tab that was a Task Run stays an ordinary Tab with its Panes. Pane env no longer gets `RADE_TASK`, `RADE_TASK_FILE`, `RADE_TASK_WORKTREES`, `RADE_INITIATIVE`, `RADE_INITIATIVE_DIR`.
6. **Files on disk are left alone.** `<root>/.rade/projects/*/tasks/`, `batches/`, `initiatives/`, `reports/`, `digests/`, `<root>/.rade/events/` and `verify/` logs are never deleted, moved, rewritten or read by 0.8. They stay readable Markdown / JSONL for the owner. `task`, `profiles`, `batch` and `report` leave the layered-config allow-list (ADR-0017 decision 4); a layer still setting them is reported `ignored (removed in 1.0.0)`, never an error.
7. **PRD numbers are kept.** R33–R70, R73–R81, R85 and R95 keep their headings with ` — Removed (1.0.0)` and one line pointing to `git show v0.7.1:docs/PRD.md`; their old ADRs carry `Superseded by ADR-0033 (1.0.0).` `scripts/check-removed.sh` (M34) greps code, CLI help, skills and CSS for the removed words, with a written list of exceptions (CHANGELOG, old ADRs, old checks).

## Considered Options

- **Hide them in the UI, keep the engines** (what M26 and M27 did): the engines kept leaking into the sidebar, palette, menus and state, and every change paid for their tests. Rejected; tried and it produced the UI the redesign replaces.
- **Move them into a plugin or a separate binary**: no plugin system exists, and the engines depend on app internals (Tabs, Panes, Agent Status). Rejected as more work than removal, for features the owner does not want.
- **A new `METHOD_REMOVED` error kind / JSON-RPC -32601**: a second way to say "unknown method"; scripts that check `kind == "USAGE"` would break. Rejected for `USAGE` + `data.removed`.
- **Delete Task and Initiative files on upgrade**: destroys the owner's notes for no gain. Rejected; they stay untouched and unread.
- **Keep the Event Journal for Activity**: a writer per Workspace and per day, for a list nobody reads after a restart. Rejected for in-memory Activity.

## Consequences

- 1.0.0 is a breaking release (0.MINOR, ADR-0012): scripts and Agents calling the removed commands or methods get exit 2 with the ADR named; the CHANGELOG lists them under "Removed".
- E2E suites m17–m23, m25 and m27 are deleted, m26 is rewritten, m18-style Reports screenshots go. Their `docs/checks/M<n>.md` stay as history.
- Downgrading to 0.7.1 after a 1.0 start needs `state.json.v2.bak`; 0.7.1 would otherwise read version 3 as unknown.
- Activity is lost on quit by design; anything that must last is in git, `gh` or the Agent's own logs.
- A Code page user loses the docked results list; the popover covers the same answers, and `rade code … --json` gives the full list.
