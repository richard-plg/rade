## Decisions and deviations

- **Root cause, not the hypothesis.** M29 suspected `fork()` of a 65 GB process; measurements put it in io_uring's locked-memory accounting. No spawn helper was built: forks never failed (ADR-0031 considered options). The JSC reservations are virtual and stay.
- **Hover key: Ctrl+I** (VS Code's is the chord Ctrl+K Ctrl+I) plus Ctrl with the pointer resting 500 ms; **peek: Alt+F12**; **outline: Alt+Shift+O** and a Viewer header button, shown on the Code page (Ctrl+Shift+O is the Browser's). Occurrence highlight and `implementations` extras from the research table were not built (implementations already exist as Ctrl+F12).
- **Workspace symbols** come from every server for the Worktree (running ones, then one per language found), a sample file of the language opened around the request; the palette asks 150 ms after the last keystroke and again by itself while a server indexes.
- **Python**: pyright then basedpyright from PATH only (a repository's `node_modules` may supply only TS/JS servers); `ty` is configurable, not built in.
