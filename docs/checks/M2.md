## Deviations and contract changes (API.md / PRD updated)

1. **`agy` replaces `gemini`** (PRD R6.1, R16.1, R16.4; research §5 added, Gemini CLI marked superseded). agy has no SessionStart or "needs input" hook: `PreInvocation` → `running` + session id, `Stop` → `done`; its hooks print `{}` because Antigravity reads their stdout as JSON. `PreToolUse` is deliberately not hooked (it decides permissions).
2. **`rade status`**: `<state>` optional (record session id / Preset only, used by session-start hooks), new `--agent <preset>` (marks a hand-started Agent so its Subagents use its grid), new `--hook` mode (stdin/argument payload, silent, always exit 0, 2 s socket timeout).
3. **Claude hooks** also include `UserPromptSubmit` → `running`; Notification uses two documented matcher entries (`permission_prompt`, `elicitation_dialog`), not `idle_prompt` (it fires 60 s after every turn and would flip `done` to `waiting`).
4. **`wait`** also returns on `exited` (and on `error` when waiting for `done`), and accepts `error`/`running`; result `status` may be null.
5. **Limits and `parent` apply to any caller**, not only Agent callers (a shell running `rade spawn` records it as Parent).
6. **`--worktree new`** → `USAGE` "NOT_IMPLEMENTED … (M7)"; ~~`close --force` = `close`~~ — superseded, see Post-review fixes B1.
7. **Program Panes stay open after exit** (`--agent`/`--cmd`: Ghostty `wait-after-command`), status `exited`, readable; any key closes them. Shells still close on exit (M1).
8. **Scrollback budget** is a fixed 64 MiB (≥ 10,000 lines up to ~500 columns), decided when the Terminal is created: a shell Pane where you start `claude` by hand keeps your own limit.
9. **Status UI** is minimal: a caption (colored dot, name, Preset, status, unread) on Agent Panes and Title Bars. Dots on Tabs/sidebar, fallbacks and the Codex never-reported hint are M6.
10. **Session Restore**: statuses are cleared on load (no process survives); ~~restored Agent Panes re-run their launch command until M6~~ — superseded, see Post-review fixes B2.
11. **Skill install**: part of `rade setup` for Claude Code and agy (shown in the diff) instead of a separate `--skills` flag.
12. `serde_json` `preserve_order` enabled (keeps the user's key order in `settings.json`; `debug state` keys now in struct order).

UNVERIFIED (covered by the manual checks): Codex and agy pass `RADE_PANE_ID` through to hooks; OpenCode's `permission.asked` arrives in the plugin's v1 event union.
