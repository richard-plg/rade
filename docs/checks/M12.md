## Design review (one subagent, diff since 6b08082, M12 files only)

Fixed:
1. `eval` re-ran the code when a *runtime* error mentioned `SyntaxError` (e.g. `JSON.parse`) → a parse-only probe (`if (false) {…}`) in RADE's world picks expression vs statements; the code runs once (E2E check).
2. A page could forge snapshot lines through `role` / `href` with newlines → non-word roles print as `generic`, hrefs are flattened and escaped, bad refs dropped (unit test).
3. Back/forward/reload and `#hash` moves waited for a load that never comes (30 s timeout) → `back`/`forward` without history → USAGE; settle accepts "not loading after 500 ms" (E2E checks).
4. `confirm()`/`alert()` from a clicked button blocked the page and timed out → during an action (10 s window) dialogs are accepted and logged as `[dialog] …`; otherwise WebKit shows them to the user (E2E check, ADR-0011).
5. `open --pane` could navigate another Browser of the Tab, and `open` picked the first Browser while `snapshot` picked the focused one → `--pane` sets that Browser; both use one focused-first rule (unit test).
6. Port scan matched any RADE instance's `p_N` → also requires this app's `RADE_SOCKET` (unit test with another instance's process).
7. Pointer-cursor cards hid their links/checkboxes; `<a>` without `href` but with `onclick` got no ref; `role=presentation|none|generic` not flattened; SVG `click()` missing → fixed in `browser.js` (E2E card check).
8. `[::1]:3000` became https → bracketed hosts parsed; API wording for `open`; session cookies don't persist (documented); MILESTONES pointed at this file before it existed (now written).
9. `fix_scale` read `devicePixelRatio` in the page's world (page could set RADE's zoom) → RADE's world; cancelled / policy-interrupted loads no longer logged as failures.
10. Cleanups: dropped a no-op `try_close`, `SnapNode`'s unused `Serialize`, `Sel { ..w.sel }`.
Not changed: subframes can post to the console handler (documented in ADR-0011); `/proc` scans stay on the UI thread (see Known limits).

## Decisions (delegated by the owner)

- **Engine: WebKitGTK 6, the one already linked** (ADR-0011). Chromium/CDP rejected: a second engine, a window outside the layout, and a CDP port any local process could use. A web-process extension rejected for now (separate `.so` + IPC).
- **Automation = the agent-browser / Playwright MCP loop**: `snapshot` → refs → `click` / `fill` / `press`, plus `eval`, `screenshot`, `console`, `wait`, history. Snapshot format follows the owner's example (`[ref=e12] button "Save"`), indented, compact (generic wrappers flattened, labels folded into controls, 160-char names, 1,500-node cap, `-i` for refs only).
- **Isolation: named script world `rade`**, kept alive by registering the library as a user script of that world (WebKit drops an unused named world, which first broke ref stability). Results serialized by JavaScriptCore. Library errors returned as values (a throw would reach the page's error handlers as "Script error."). `eval` deliberately runs as the page.
- **Synthetic input**, with defaults emulated for the keys Agents need. Trusted input is out of reach without CDP/an extension; documented.
- **Console** via a page-world document-start hook + `radeConsole` handler (WebKitGTK has no console signal for embedders); top frame only; capped at 500.
- **Dialogs** auto-accepted only during an Agent's action; humans get WebKit's own dialogs.
- **Website data**: one persistent NetworkSession per flavor (cookies need explicit SQLite storage, found by the restart E2E), ITP off, no keyring credential storage, HTTP cache in the flavor's cache dir. Persistent cookies kept for localhost dev logins. No self-signed TLS exception (dev servers using mkcert trust the system store).
- **Placement** like the Viewer: one Browser per Tab, split right of the caller (the Agent stays visible), focus not moved for `rade browser open`; moved for the key / palette.
- **Key `Ctrl+Shift+O`**: Ghostty's `new_split:right`, which RADE's own split keys already replace (added to the collision test's justified list). In-page keys `Ctrl+L`, `F5`, `Alt+Left/Right`.
- **Ports (included, cheap)**: `/proc/net/tcp{,6}` LISTEN inodes ↔ `/proc/<pid>/fd` sockets of our processes, Pane by `RADE_PANE_ID` + own `RADE_SOCKET` (a daemonized server that keeps its env still counts). Shown in the sidebar row tooltip (scanned on hover, cached 2 s), palette rows "Open localhost:<port>" (scanned on palette open), `rade browser ports`, and used by `Ctrl+Shift+O`. No periodic scanning.
- **URL bar**: localhost first; no web search (a word without a dot is an error), so nothing leaves the machine by accident.
- **limux**: its browser tab (MIT) informed the header shape and localhost-first input; no code copied (THIRD_PARTY.md notes it).

## Known limits

- Synthetic events (`isTrusted` false); no file upload, drag and drop or hover-only menus by ref.
- No iframe contents in snapshots (listed only); no closed shadow roots.
- `/proc` port scan ≈ 20 ms with 1,400 processes, on the UI thread at palette open / tooltip hover. Move it to a thread if the palette open feels slow.
- History and form state are not restored (only the URL). Session cookies end with the app.
- Screenshots need the Browser rendered (a Browser in a hidden Tab may fail with a clear error).
- No `dialog dismiss` command (dialogs during actions are accepted).
