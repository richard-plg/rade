## Notes

- Plan deviations, all recorded in `PLAN-voice.md` or here:
  - On `error_max_turns`, RADE sends one more turn: `Write the prompt now…`.
  - The STT reply's status comes from curl's `write-out`.
  - `Event::Tap` carries `at_ms`.
  - A failed live partial is skipped unless the server is unreachable.
  - `ph-list` was missing from the bundled icons and was added.
  - whisper-server needs `-l auto`: without it, a request with no `language` is decoded as English.
- `max_turns` applies to Claude Code only; Codex has no turn limit (the Settings description says so).
- Codex as the voice agent is covered by unit tests over a recorded `codex exec --json` run only. No E2E drives it.
