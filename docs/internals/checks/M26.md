## Decisions and deviations (ADR-0028)

- Membership is the recorded `project` only; branches give one-click suggestions, never placement; main checkouts are pinned; a one-time freeze records what the 0.3.1 rule showed under exactly one Project.
- The UI never refuses on readiness: Needs info + Fix with Claude / Start anyway, Status → ready logged; the CLI, socket and `batch run` keep every gate. The Run dialog's runs are the owner's: their readiness and `inbox` are not judged for that run (only on the GTK thread, never over the socket).
- `review: agent-then-human` (new value) makes "Claude reviews, then me" honest; `batch add --run`; `project.set` with `toml_edit`; a Verify command typed in Project settings counts as confirmed.
- Batch and Initiative rows stay in the sidebar under their Project (they are work in progress); the Batch row opens the Tasks page; the Batch page stays in the palette and `debug.batch`.
- An empty Project (no Worktree, no work) shows folded unless unfolded; Projects are listed by id (as before).
- Project settings lists the Sources × Named Bases cells as rows (Adwaita), not a grid.
