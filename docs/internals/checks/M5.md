E2E setup: as M4 (headless Weston, private D-Bus, temp HOME/XDG incl. `XDG_CACHE_HOME`). Headless Weston has no seat, so `wl-copy`/`wl-paste` refuse to run ("The compositor does not seem to implement seat"). The test therefore puts data on RADE's own GDK clipboard (`rade debug clipboard MIME=FILE…`, several MIME types offered together) and runs `rade debug action paste`, which invokes Ghostty's `paste_from_clipboard` binding on the focused Terminal — the same code path as `Ctrl+Shift+V` (Ghostty → `read_clipboard_cb` → source choice → GDK read → completion → Ghostty's paste encoding). The Terminal runs a sink (`stty raw -echo; printf '\e[?2004h'; exec cat -v`), so a bracketed paste shows as `^[[200~…^[[201~` on screen.

## Deviations and decisions

1. **Clipboard in E2E** is RADE's own (in-process GDK clipboard) because headless Weston has no seat for `wl-copy`; everything from Ghostty's paste binding on is the production path. The Wayland data-offer transfer itself is covered by M5-1/M5-3.
2. **Text beats image** when both are offered (e.g. an office app copying a cell offers text + a picture). A browser's "Copy image" offers `image/png` + `text/html` (no plain text), so it pastes as an image.
3. **Quoting**: paths with special characters are single-quoted like GNOME Terminal's drops (`'/a b.png'`, `'it'\''s'`), which Agents' pasted-path detection understands; only control bytes / invalid UTF-8 use Bash's `$'…'`. Plain paths (the usual paste file) stay bare. This also changes the pre-M5 file drop (limux used `$'…'` for any path needing quotes).
4. **Drop type order**: `Texture` before `FileList`, because a browser's image drag also offers a uri-list of `https://` URLs; a file manager offers no image data, so file drops still paste paths.
5. **OSC 52 reads** go through the same clipboard read callback, so a program's OSC 52 read of an image-only clipboard would also save a PNG and get its path — only after Ghostty's `clipboard-read` consent dialog. PNG encoding runs on the UI thread (`ponytail:` note in `terminal/clipboard.rs`).
6. **Paste file names** use local time (`tm_gmtoff`), so they match the user's clock.
7. **API**: hidden `debug.clipboard`, `debug.drop`, `debug.action paste` (docs/API.md).
