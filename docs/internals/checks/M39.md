## Fix round 1 (review findings)

| Finding | Fix (`e2763b8`) | Proof |
|---|---|---|
| A poll between a turn's first lines and its sample set `format-changed` and hid every figure | `ScanTrack`: `format-changed` only after 100 log lines in a row (over any number of scans) with no sample; a statusline `usage.record` clears it | `usage::tests::a_turn_without_its_sample_yet_is_not_a_format_change` (failed to build first) |
| A limit past its `resets_at` kept its old % (Tightest, Usage page, Statusline cell, `+` menu, forecast Toast), and its `reset` line never came | `limits::as_of` (0 %, not blocked, no reset) in `report::summary` / `account_limits`, `usage.get`, `snapshot`; `limits::reset_events` on each poll (once per window); `limit_events` compares a new sample against 0 % once the old window ended | `a_window_past_its_reset_counts_as_zero`, `reset_events_when_the_clock_passes_a_reset`, `limit_events_count_an_ended_window_as_zero` (failed first: it said `reset`, not `over 80%`), `summary_and_account_limits_drop_a_passed_window`; m39 R110-h still 3 lines once each |
| Logs untouched for 90 days were skipped on the first scan only, read in full on the next poll | `tail::scan_login` applies the cutoff on every scan; the app calls it | `tail::tests::logs_untouched_for_the_retention_stay_unread_on_every_scan` |
| `rade account default` was ignored after `Next agents use <other>` | `State::clear_next_default`, called by `account.set_default` | `account_tests::r110_g_next_default_changes_later_agents_only_in_memory` (extended) |
