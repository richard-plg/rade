## Decisions and deviations (ADR-0030)

- Impact lives in the Review Pane as a section under the header behind an **Impact** toggle (the explicit action that may start a server), not on the Code page; navigation results from diff lines still go to the Code page.
- A jump from the Review opens the Tab's Viewer (a new one beside the Review when there is none) as a code jump, so Alt+Left walks back through jumps made from the Review.
- Removed lines: the name's declaration in the current tree (text search) → the query from there; else `git grep -w` at the base, state `base`. No second server at the merge-base.
- Budgets: UI 30 s (first ask without waiting, then an automatic retry that waits), prompts 20 s, CLI `--wait` 60 s; servers get ¾, text matches the rest.
- Review Comments sent to an Agent get no Impact section (the owner chose what to say). "Comment on an Impact row" (research § 5.3) is left for later: Review Comments anchor to diff lines, callers are outside the diff.
- Not in M29 (per the plan): hover, outline, workspace symbols in the palette, peek, Python / Go servers (M30).
