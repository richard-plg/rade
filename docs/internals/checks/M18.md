## Decisions and deviations (recorded)

- R-IDs R41–R47 and ADR-0019 follow M17's R40 / ADR-0018.
- The draft command runs in the Workspace root (the plan said the report folder: it must not exist before a draft succeeds, R43-c).
- Commits are matched on their **local commit date** over a month-bounded `git log --all` instead of `--since/--until` on the day: git stops walking at the first commit dated before `--since`, so one commit with a skewed date hid later ones.
- Agent events are found by comparing Pane snapshots around every model update (`App::update`), so hooks, `notify`, `send`, child exit and the idle watcher all log through one place. `agent.end.secs` = time since the Pane became `running`.
- A Digest's Project section is cut from the stored Workspace Digest (`## <Project name>`), so hand edits reach Project Reports.
- `--json` on `report export` prints the webhook body (Slack `{text}`, DingTalk robot payload); the whole result for `md`.
- GTK offers the copied text both as UTF-8 and as legacy `text/plain` (non-ASCII escaped); chat apps take UTF-8, so the live check reads `text/plain;charset=utf-8`.
- The Reports page is cleared by any Source / Tab / Pane selection (model) and replaces / is replaced by the Tasks page.
- DingTalk rules follow DingTalk's robot docs (headings, bold, italic, links, images, quotes, flat lists); tables, code and strikethrough are converted — `docs/internals/research/dingtalk-markdown.md`, unverified until the real paste.
- Not built (plan "skipped"): reading Agent session logs into Digests, webhooks in RADE, a Workspace roll-up of Project Reports, journal retention.
