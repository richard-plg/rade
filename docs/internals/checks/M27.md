## Decisions and deviations (ADR-0028 item 7)

- New Initiatives record `flow: 2` and merge Concept into Spec; nothing migrates existing ones; `[initiative] gates = "full"` opts new ones into the seven phases.
- The UI's four steps map Discovery → Brief, Concept / Spec / Design → Spec, Plan, Build (Done after).
- The review bar and the card call the same UI-only dialogs as the Initiative page; no socket or CLI path approves (ADR-0027 stands).
- An Initiative's milestone Batch is shown through its card, not as a Running together group.
- Presets are layered config over three built-ins; `stop_on` keeps a preset's count (2) while "Stop after a failure" stays ticked.
