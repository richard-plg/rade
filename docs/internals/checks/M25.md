## Decisions and deviations (recorded in ADR-0027)

- An Initiative is a folder beside `tasks/` and `batches/`; its phase is RADE's (`state.json` `initiatives`); every gate is a button on the Initiative page; documents' history is RADE's read-only Versions (the Report Versions code); per-line comments reuse the Review Comment type; design feedback is a Browser Annotation on the prototype opened beside the Agent.
- Discovery is the Concept phase's first draft; the Agent asks the owner in its Terminal.
- Build: milestones in order, one at a time; each is one Batch (`initiative: I-n`, `merge: integration`) of Tasks labelled `I-n/M<k>` (`rade task add --label`, new) on `initiative/I-n`, made by RADE and reused; an independent acceptance Agent writes `checks/M<k>.md`; the owner continues.
- Shared cap `[initiative] agents` (default 4) via `Obs::Slots`; conflicts via `git merge-tree --write-tree` every 10 s when a branch moved.
- The design-review Agent is the Initiative Agent's to spawn; RADE doesn't continue an Initiative Agent after a restart; no journal events of its own.
