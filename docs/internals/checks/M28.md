## Decisions and deviations (ADR-0029)

- Config is `[code]` + `[code.server.<rust|typescript>]` (one layered key), not a separate `[lsp.<lang>]` table; the per-repository switch is `[sources.<id or name>] code = false` (the owner's own files, no trust step needed). `idle_minutes` / `max_servers` count from `config.toml` only.
- Results that the server can't give are never an error: `code.query` always answers, with `state` + `hint`, and text matches where they mean something (none for callees / symbols).
- The UI asks with no wait and retries an indexing answer by itself; `rade code` waits 20 s by default (`--wait`), since an Agent prefers a precise answer.
- The answer's `source` is the server's `serverInfo.name` (e.g. `rust-analyzer`), else the command's name.
- A new server gets 1.5 s to report work before it counts as ready; a server that never reports (the fake) is ready after that.
- Code page call hierarchy is one level (callers at their call sites, callees at their definitions); expanding level by level is left for later.
- Not in M28 (per the plan): Review Pane navigation and the Impact list, `rade code impact`, Reviewer / Judge prompts (M29); hover, outline, workspace symbols in the palette, peek, Python / Go (M30).
