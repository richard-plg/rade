## Decisions and deviations (recorded)

- ADR-0022: field edits write only their line (no `updated:`, no Log); status keeps the M17 path; the description is swapped with an optimistic check; a title change keeps the file name; Brainstorm runs in a new Tab of the Workspace's General (the page can't host a Pane); the Agent, not RADE, creates the Tasks after the owner confirms.
- An inline edit is written only if the result parses and reads back the typed value; otherwise "edit the file" (odd YAML is never broken).
- Text fields are written on Enter / focus leave and only if the owner changed them; the description autosaves 0.7 s after typing stops.
- Narrow windows (< 900 sp): the Detail overlays the List (adw breakpoint); not exercised by the E2E (fixed 1400 px window).
- A section header is folded by a click (headers aren't selectable); keyboard Enter on a header no longer folds.
- Not done (low, acceptance): CRLF files get LF on the edited line (D4); a `# comment` inside a block list is dropped when the list becomes one line (D8, the comment above it is kept); an Agent's plain `>>` append landing between RADE's re-read and rename can still be lost (D9 remainder, `ponytail:` in `task::edit`).
