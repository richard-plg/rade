## Limits and release gates

Human usability with five new users, actual desktop screen-reader/keyboard experience, GPU/IME, installer upgrade, long unattended runs and broad website compatibility are not established by these changes. A known-host restriction cannot isolate unknown WebKit crashes. Provider authentication, quotas and permissions remain normal external dependencies; no bypass or fake cost estimate was added. Real acceptance uses copied credentials in temporary isolated configuration and must not publish those files.
