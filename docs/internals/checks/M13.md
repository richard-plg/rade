## Decisions (delegated by the owner)

- **Tab menu** = libadwaita's own (AdwTabView `menu-model`, refilled in `setup-menu` for the right-clicked Tab): native look, keyboard and positioning. Items that would do nothing are left out rather than greyed (GMenu items can't be disabled per target without per-action state). Trade-off: the menu's length varies.
- **Several Tabs ask once, one Tab doesn't**: the dialog appears only when a running / waiting Agent would be stopped or a Fan-out Tab stays open; a single Close keeps the existing close-button behaviour. The CLI never asks (like `rade close`); `--force` = SIGKILL at once.
- **Fan-out Tabs are never closed on the side**: Others / Right skip them and say so; the Tab alone opens the existing Discard dialog (CLI: `USAGE` naming `rade fanout discard`). Trade-off: one more step, but never an accidental `git worktree remove --force`.
- **Duplicate** opens a shell (not the Agent: a second process on one session would fork it) in the focused Terminal's cwd, right after the source, selected; the name isn't copied.
- **No new default keys.** `Ctrl+Shift+F` stays Ghostty's own `start_search` binding; RADE implements the bar Ghostty asks for (`START_SEARCH`), so the key collision test is unchanged. New palette actions instead: Duplicate Tab, Close Tab, Close Other Tabs, Close Tabs to the Right, Rename Pane…, Find in Terminal…, Rename Project…, Pause Project, Resume Project.
- **General** gets Rename… and Open in Files only (it is `$HOME`; can't be paused or removed). Its id stays `general`.
- **Open in VS Code** = `[viewer] editor` with the Project folder (VS Code focuses a window that has it open); hidden when that editor isn't on `PATH` (no `$EDITOR` fallback: a folder needs a GUI editor). **Open in Files** = the folder's default app through GIO.
- **Remove** always asks in the UI (the CLI is unchanged); the dialog says the folder and RADE's Worktrees stay on disk. Panes close like `rade close`.
- **Pause computes the restart state at pause time** (each Pane's Session Restore command, `interrupted` for a turn in progress — the M11 rule), saved before any signal: a crash while paused restores the same thing, and Resume is just "start them". Agent hooks firing as the Agents exit only record ids, never a status. Trade-off: an Agent that finishes its turn during the SIGHUP grace still comes back `interrupted` (safe side: the user prompts it).
- **Every Pane of a paused Project becomes a placeholder**, Viewers, Reviews and Browsers too: they hold resources (the Review polls git every 3 s, a WebView process) and "paused" then means one thing. Trade-off: a Browser reloads its URL on Resume (history lost, like a restart).
- **What a paused Project still allows**: list, close, focus, rename, tab rename / close, wait. It refuses anything that adds a Pane (checked in the model's Tab / split primitives, so every path is covered) and send / read. **Pausing while a Fan-out works** needs `--force` (CLI) / a confirmation (UI). The UI asks when Agents are running; the CLI pauses directly, like `rade close`.
- **Pane names** must be unique among the Panes *running* in the same Worktree and not look like `p_<digits>` (ids win in lookups); elsewhere they may repeat (lookups prefer the caller's scope). Rename-only rule; `spawn --name` keeps its old behaviour. A named Pane now shows a caption (name, title), so a rename is visible on screen.
- **Project rename** changes the display name only: the id addresses it in the CLI, `RADE_PROJECT`, Worktree folders and `[projects.<id>]`. A new name may not equal another Project's name or id. `[projects.<name>]` config written with the old name stops matching: use the id there.
- **`rade rename <pane> <name>`** top-level, like `close` / `focus` (Pane verbs are top-level); `rade tab …` and `rade project rename|pause|resume` are subcommands like the existing groups. `<tab>` accepts an id or a name / label, resolved like Pane names.
- **Terminal right-click** follows Ghostty's GTK app: the right button goes to Ghostty first; the menu opens only when Ghostty leaves it unconsumed (a program with mouse reporting gets it; Shift+right-click reaches the menu unless `mouse-shift-capture` lets the program take Shift too; `right-click-action` applies). Ghostty selects the word or link under the pointer, so Copy is offered then. "Open …" appears when that word resolves like a Ctrl+click (an existing file or a URL) and opens it the same way.
- **Search** is Ghostty's (`search:` per change, debounced 150 ms by the entry; its highlights and scrollback); the count reads like Ghostty's own (`selected/total`, 0 before Enter). The bar sits top right over the Terminal; the last needle is kept for the next open. limux's bar wiring (MIT) was the starting point (THIRD_PARTY.md).
- **Not done**: undo for closed Tabs; Pause / Resume of a single Worktree; dimming the paused Project's Tabs in the palette.
