# RADE — Milestones

One milestone = one or a few agent sessions = one PR-sized vertical slice that runs end to end. Do them in order; a milestone is done only when every exit criterion passes and is recorded in `docs/internals/checks/M<n>.md` (commands run + results + screenshots path).

## M0 — Spike + limux audit (de-risk; 1–3 days)
Goal: prove the stack on the reference machine before any product code.
1. Build the pinned Ghostty fork (`-Dapp-runtime=none`) and a minimal GTK4 window with one embedded Ghostty surface running `$SHELL`.
2. Exit criteria (all must pass, else stop and write an ADR revisiting ADR-0001):
   - Renders and scrolls smoothly on Intel iGPU **and** NVIDIA (`__NV_PRIME_RENDER_OFFLOAD=1 __GLX_VENDOR_LIBRARY_NAME=nvidia`) under Wayland.
   - IBus Vietnamese input with visible preedit (R9 AC).
   - Two surfaces in a `GtkPaned`; hiding one stops its rendering.
   - `ghostty_surface_read_text` returns scrollback lines (or document the limit).
   - First `bench/` numbers for R4.
3. Audit limux (read the code, run it): workspace model vs Project→Worktree→Tab, IME, socket API shape, code quality, test coverage. Output `docs/internals/research/limux-audit.md` ending with a recommendation **fork** or **build**, then record the decision as ADR-0009 (including final crate layout).
